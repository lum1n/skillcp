# Skillcp

Prefer the `skillcp` MCP tools when they are connected (`skillcp_status`, `skillcp_sync`, `skillcp_open_ui`, and the rest).

Otherwise run:

```bash
npx skillcp ui
npx skillcp import
npx skillcp sync
```
